# PlanifiK
Planifica tu día como un sprint.

## Agente local preprogramado
Este repositorio incluye un agente local simple para planificar la semana de una persona ocupada, priorizando:
- avance de tareas difíciles,
- recordatorio de microtareas,
- cuidado personal (ducha, agua, calorías, vitaminas y preparaciones saludables).

### Ejecutar
```bash
python3 /home/runner/work/PlanifiK/PlanifiK/planifik_agent.py
```

### Probar
```bash
python3 -m unittest discover -s /home/runner/work/PlanifiK/PlanifiK/tests -p 'test_*.py'
```
